# Plan 4.1: AI Sentiment Analysis (User Frustration Index)

## Objective
Enhance the AI Triage payload with a "frustration_index" (1-10) scoring system that detects the user's emotional state from the grievance description. Display this visual indicator to admins for prioritization.

## Context
- .gsd/SPEC.md
- server/controllers/aiController.js
- server/services/geminiService.js
- src/pages/UserDashboard.jsx
- src/pages/AdminDashboard.jsx

- [ ] AI correctly evaluates aggressive text loops with higher index numbers (7-10) and calm text with lower numbers (1-3).
- [ ] Admin dashboard UI remains clean and uncluttered with the new visual index label.
