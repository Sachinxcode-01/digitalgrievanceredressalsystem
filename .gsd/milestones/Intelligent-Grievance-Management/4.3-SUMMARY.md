## What Was Done

2. **Global Theme Provider**: Implemented theme state management in `App.jsx` using `useState` and `localStorage` persistence.
3. **Dynamic Body Class**: Integrated a `useEffect` in `App.jsx` that applies the `theme-midnight` class to the HTML `body` dynamically, allowing for instant global style switching.
4. **Theme Toggle UI**: Added a sleek Moon/Sun toggle button in the `Layout.jsx` header.
5. **Reactive Gradients**: Updated `BackgroundGradientAnimation` to be reactive to color prop changes, enabling smooth transitioning of the animated background when switching themes.
