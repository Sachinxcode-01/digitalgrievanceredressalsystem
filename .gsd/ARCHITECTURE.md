## Overview

The Digital Grievance System is an enterprise-grade full-stack web application designed for institutions to collect, triage, and resolve user complaints dynamically. It leverages Google Gemini AI for smart categorization, Supabase for realtime database communication, and Nodemailer for live SMTP email routing.

## Components

### 1. Client App (React)
- **Purpose:** Provide an immersive Glassmorphism UI for users and admins.
- **Location:** `src/`
- **Dependencies:** `react`, `framer-motion`, `recharts`, `@supabase/supabase-js`, `lucide-react`

### 2. Express Backend
- **Purpose:** Intercept Grievance submissions from frontend to execute protected features (Emailing & AI).
- **Location:** `server/`
- **Dependencies:** `express`, `nodemailer`, `cors`, `dotenv`

### 3. AI Triage Service
- **Purpose:** Analyze raw ticket complaints, predict urgency, and auto-route to proper departments.
- **Location:** `server/services/aiService.js`
- **Dependencies:** `@google/genai`

### 4. Email Pipeline
- **Purpose:** Dispatch dynamic HTML emails to users for OTPs and Ticket Receipts, and alert Admins on new action items.
- **Location:** `server/services/emailService.js`
- **Dependencies:** `nodemailer`

## Data Flow

1. User authenticates via Supabase Auth or backend Node OTP.
2. User fills out Grievance UI form -> Hits `AI Auto-Fill` (requests `server/api/ai/analyze`).
3. User submits ticket -> POSTs payload to `server/api/grievances`.
4. Express Server independently saves the record in `Supabase DB`, then commands `emailService.js` to dispatch SMTP emails to the User and Admin.
5. `UserDashboard` and `AdminDashboard` automatically render the new ticket utilizing Supabase Realtime Channels (`postgres_changes`).
