v2.0 Architecture

Backend Infrastructure

A highly optimized, layered MVC architecture built with Node.js and Express.js, powering the Digital Grievance Redressal System.

⚙️ Config Layer (/config)

Centralizes all environment variable bindings and external database connections. The supabase.js file initializes the Supabase client utilizing service role keys for secure backend operations, ensuring zero-trust auditing.

🎮 Controllers Layer (/controllers)

Acts as the traffic director for the application. It receives HTTP requests from the routes, extracts data, passes it to the services for processing, and formats the final JSON response. It handles the AI-Powered Triage requests and delegates execution.

🧠 Services Layer (/services)

The core intelligence of the application resides here.

  • geminiService.js handles interactions with Google Gemini 1.5 Flash for smart categorization and urgency prediction.
  • emailService.js utilizes Nodemailer for sending dynamic HTML receipts and OTPs.

🛣️ Routes Layer (/routes)

Defines the API endpoints (e.g., /api/v1/grievances) and maps them to specific controller functions. Applies essential Express middleware for authentication (Supabase JWT verification) and input validation.
